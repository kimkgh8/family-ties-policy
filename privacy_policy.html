가족 사이 개인정보처리방침

시행일: 2026년 11월 4일 · 개발자: ROOT KIM

계정 및 데이터 삭제 요청개인정보 문의

가족 사이는 가족이 일정·할 일·준비물을 함께 챙기는 Android 앱입니다. 로그인 없이 쓰는 기기 내 자료와 로그인 후 참여한 가족의 공유 자료는 별도로 유지됩니다. 기기의 기존 자료를 가족에게 자동으로 전송하지 않습니다.

1. 처리하는 정보와 목적

  • 기기 내 자료: 이용자가 입력한 일정·날짜·시각·시간대·제목·메모·중요 표시, 구성원 이름/별칭, 담당 할 일·기한·완료 상태, 연결 일정, 작성 중 초안, 휴지통 자료를 앱 전용 저장 공간에 보관합니다. 작성·조회·검색 조건에 따른 목록 표시·복원을 위한 처리입니다.
  • 선택 계정 및 가족 공유: 이메일·비밀번호 인증을 선택하면 Firebase Authentication이 이메일·비밀번호 등 인증 정보와 계정 식별자를 처리합니다. 운영자는 이용자의 비밀번호를 조회하지 않습니다. 로그인 후 가족을 만들거나 초대에 참여하면 가족 이름·구성원 이름/별칭·계정 연결·역할, 해당 가족에서 작성한 일정·할 일·준비물·메모·완료 상태, 변경 작성자와 시각·확인 상태를 서버에 보관합니다. 가족 구성원 간 열람·공동 편집·변경 전달과 동기화가 목적입니다.
  • Google 로그인(선택): 선택한 Google 계정의 ID 토큰을 Firebase Authentication에 전달하여 계정을 인증합니다. Google 계정 식별자·이메일·이름·프로필 사진 주소 등이 Firebase 인증 계정에 포함될 수 있습니다. 앱은 Google 연락처·메일·캘린더를 조회하지 않습니다. 인증 제공업체의 이메일·이름·프로필 사진을 가족 공유 문서에 자동 복사하지 않습니다.
  • 카카오 로그인(선택): 카카오 SDK로 발급받은 액세스 토큰을 운영자의 인증 검증 서버에 HTTPS로 전송합니다. 서버는 카카오에 토큰의 앱·유효기간·회원 식별자를 확인하고, 회원 식별자를 이용한 Firebase 계정과 로그인 토큰을 발급합니다. 액세스 토큰은 검증 중에만 처리하고 서버에 저장하거나 로그로 기록하지 않습니다. 앱의 카카오 SDK 토큰 저장소는 교환 종료 시 비웁니다. 카카오 닉네임·프로필 사진·이메일·전화번호·친구 목록은 요청하거나 조회하지 않습니다. Firebase 계정 식별자와 계정 연결은 계정 유지·가족 접근 확인을 위해 보관합니다.
  • 초대 및 전송 대기: 초대의 유효 기간·사용·취소 상태를 처리하며, 서버에는 초대 코드의 해시를 보관합니다. 연결이 끊겼을 때 작성한 공유 변경은 기기에 보관하고 재연결 후 전송합니다. 충돌 시 이용자가 유지할 내용을 선택합니다. 한 항목의 전송이 끝나기 전 추가 변경이 제한될 수 있습니다.
  • 삭제 요청과 지원: 앱에서 계정 삭제를 요청하면 해당 인증 계정의 계정 식별자·이메일(있는 경우)·서버 요청 시각을 운영자가 확인할 수 있는 요청으로 기록합니다. 이메일로 문의하면 발신 주소와 직접 보낸 내용을 본인 확인·답변·요청 처리에 사용합니다. 비밀번호·인증코드·불필요한 신분증은 요구하지 않습니다.
  • 서비스 접속 정보: Firebase 인증 과정에서 보안 및 악용 방지를 위한 IP 주소, 앱·SDK·기기 플랫폼 정보 등이 처리될 수 있습니다. Firebase Android 데이터 공개 안내를 참고하세요.

2. 선택 기능과 공유 범위

기기 내 기능은 로그인 없이 사용할 수 있습니다. 가족 공유를 사용하려면 이메일·비밀번호 가입 후 이메일 확인, 또는 Google·카카오 계정 로그인이 필요합니다. 로그인 후 가족을 만들거나 초대를 확인해 참여합니다. 소셜 로그인만으로 다른 가족에 자동 참여하지 않습니다. 공유 가족에 입력한 자료는 그 가족의 구성원이 볼 수 있으며 편집할 수 있습니다. 이름이나 메모에는 필요한 최소 정보만 입력하고 다른 사람의 정보를 넣기 전 해당 사람의 의사를 확인해 주세요.

가족에게 보일 이름/별칭은 앱에서 직접 입력합니다. 초대 공유를 선택하면 Android 공유 창을 통해 선택한 앱에 초대 코드와 참여 안내를 전달합니다. 공유 문구에는 이메일·구성원 이름·일정 내용을 넣지 않습니다. 초대 코드를 받은 사람은 가족 참여에 사용할 수 있으므로 받을 사람을 확인해 주세요.

연락처·사진·위치 전체를 자동으로 수집하지 않으며, 기기 위치를 추적하지 않습니다. 현재 버전에는 광고·인앱 결제·행동 분석·사진 업로드·기기 푸시 알림 기능이 없습니다. 앱 내 변경 알림과 기기 알림은 구분됩니다. 네트워크 상태는 오프라인 변경의 전송 시점을 판단하는 데 사용합니다.

3. 외부 서비스와 안전성

Google Firebase의 Authentication과 Cloud Firestore를 계정 인증·가족 데이터 보관·동기화에 사용합니다. Firestore 데이터베이스는 서울 리전에 설정되어 있습니다. 인증·보안·지원 등 일부 처리는 Google의 서비스 인프라에 따라 대한민국 밖에서 이루어질 수 있습니다. Firebase 개인정보 및 보안 안내와 Google 개인정보처리방침도 참고하세요.

카카오는 선택한 계정의 로그인과 토큰 검증을 처리합니다. 카카오 개인정보처리방침을 참고하세요. 운영자의 카카오 인증 검증 서버는 Oracle Cloud 인프라에서 실행되며 HTTPS 연결에는 Tailscale Funnel을 사용합니다. 이 서버는 가족의 일정·메모나 카카오 프로필을 조회하지 않습니다. 인프라 제공 과정의 접속 정보 처리는 각 제공처의 정책을 따릅니다. Oracle 개인정보 안내 · Tailscale 개인정보처리방침

서비스 통신에는 HTTPS/TLS를 사용하고, 가족 데이터 접근은 인증과 서버의 가족 소속 규칙으로 제한합니다. 기기 내 자료는 앱 전용 저장 공간에 보관합니다. 이용자가 선택한 가족 공유 및 서비스 제공을 위한 처리 외에 자료를 광고 목적으로 판매하거나 공개 게시하지 않습니다. 정책 사이트는 GitHub Pages에서 제공되며 페이지 접속에 필요한 기술 정보는 GitHub 개인정보처리방침에 따라 처리될 수 있습니다.

4. 보유·삭제 및 이용자 권리

  • 기기 내 자료와 가족 공유 자료는 이용자가 삭제하거나 계정 및 데이터 삭제를 요청할 때까지 보관합니다. 휴지통 이동은 영구 삭제가 아니며 복원을 위해 보관됩니다. 앱 삭제는 해당 기기의 앱 저장소를 제거하지만 서버의 공유 자료를 자동으로 지우지는 않습니다.
  • 로그아웃 시 해당 계정의 기기 캐시·작성 중 초안·미전송 변경을 정리합니다. 미전송 변경을 지우면 서버로 전달되지 않습니다. 로그인 전의 독립 기기 자료는 계정 자료와 구분됩니다.
  • 계정 삭제 요청은 로그인한 계정에서 접수된 요청과 필요한 추가 확인으로 본인 및 삭제 범위를 확인한 후 처리합니다. 이메일 계정은 등록 이메일을 확인할 수 있고, 이메일이 없는 카카오 계정은 앱의 인증된 계정 요청을 기준으로 확인하며 이메일 등록을 필수로 요구하지 않습니다. 본인 확인이 완료된 요청은 원칙적으로 30일 이내 처리합니다. 계정 인증 정보·개인 프로필·가족 연결·개인 식별 자료와 요청 범위의 기록이 삭제 또는 비식별 처리 대상입니다. 다른 구성원이 있는 공동 가족의 자료를 일괄 삭제하지 않으며 공유 기록과 관리자 이전이 필요한 경우 처리 범위를 안내합니다. 마지막 구성원의 가족이라면 해당 가족의 기록·구성원·초대·변경 이력도 정리합니다.
  • 가족에서 구성원을 제거하면 해당 계정과 가족의 연결을 해제합니다. 기존 일정·할 일은 보존하며 담당자가 없어진 항목은 담당 없음으로 표시합니다. 구성원 제거는 해당 인증 계정 삭제와 다릅니다. Google·카카오의 연결 해제만으로 가족 사이의 계정과 공유 자료가 모두 삭제되는 것은 아니므로 별도로 계정 삭제를 요청해 주세요.
  • 삭제 요청 및 이메일 문의 기록은 확인·답변·처리 목적이 달성되면 삭제합니다. 별도의 법적 보관 사유가 생기면 해당 항목·사유·기간을 별도로 안내합니다. Google이 보안·접속 처리 과정에서 보관하는 기술 정보는 해당 제공처의 정책을 따릅니다.
  • 이용자는 자료를 직접 수정하고, 가족에서 탈퇴하거나, 계정·일부 데이터의 열람·정정·삭제를 요청할 수 있습니다. 계정 삭제와 가족 탈퇴는 다르며, 탈퇴만으로 인증 계정과 모든 공유 기록이 자동 삭제되지는 않습니다.

5. 계정 및 데이터 삭제 요청

앱의 가족 설정 → 계정과 가족 공유 → 계정 삭제 요청에서 요청을 접수할 수 있습니다. 즉시 자동 삭제되는 방식은 아닙니다. 앱을 사용할 수 없거나 이미 삭제했어도 계정 및 데이터 삭제 요청 페이지에서 이메일로 요청을 시작할 수 있습니다.

6. 변경 및 문의

처리하는 정보나 기능이 변경되면 이 방침과 스토어 데이터 공개 내용을 함께 갱신합니다.
