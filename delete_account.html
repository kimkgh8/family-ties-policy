이메일로 삭제 요청하기

직접 보낼 주소: asdlkjd2@gmail.com

요청 방법

  1. 제목에 “가족 사이 계정 및 데이터 삭제 요청”을 적어 주세요.
  2. 사용한 로그인 방법(이메일·Google·카카오)과 계정 전체 삭제 또는 특정 데이터 삭제 중 원하는 범위를 알려 주세요. 이메일이 등록된 계정은 등록한 이메일에서 요청하면 본인 확인에 도움이 됩니다. 이메일이 없는 카카오 계정도 삭제를 요청할 수 있으며 새 이메일 등록을 요구하지 않습니다. 앱을 사용할 수 있다면 로그인한 상태에서 앱 내 삭제 요청을 먼저 접수해 주세요.
  3. 운영자가 인증된 앱 내 요청 또는 필요한 추가 확인으로 요청자를 확인하고 처리 범위를 안내합니다. 앱을 사용할 수 없거나 계정을 특정할 수 없는 경우 이용 가능한 본인 확인 방법을 안내합니다. 비밀번호·인증코드·인증 토큰·불필요한 신분증은 보내지 마세요.

삭제 범위와 처리 기간

  • 해당 계정의 인증 정보·프로필·가족 연결·개인 식별 자료 및 요청 범위의 기록이 삭제 또는 비식별 처리 대상입니다.
  • 마지막 구성원의 가족은 가족 이름·구성원·일정·할 일·준비물·메모·초대·변경 및 확인 기록까지 정리합니다.
  • 다른 구성원이 있는 공동 가족은 다른 사람의 자료까지 임의로 삭제하지 않습니다. 관리자 이전, 공유 기록의 삭제·비식별 처리 범위를 본인과 확인합니다.
  • 본인 확인이 완료된 요청은 원칙적으로 30일 이내 처리합니다. 추가 확인이 필요하면 먼저 안내합니다. 삭제 요청과 문의 기록도 처리 목적이 달성되면 삭제합니다. 법적 보관이 필요하면 사유와 기간을 안내합니다.
  • 로그인 전 독립 기기 자료와 다른 구성원·다른 계정의 자료는 해당 계정 삭제로 자동 제거되지 않습니다. 본인 기기의 앱 저장소는 앱 삭제로 제거할 수 있습니다.

Google·카카오 서비스에서 앱 연결을 해제하는 것과 가족 사이 계정 삭제는 별개입니다. 가족 사이 계정과 데이터 삭제는 위 방법으로 요청해 주세요.

앱에서 요청하기

가족 설정 → 계정 → 계정 삭제 요청을 선택해 접수합니다. 이는 운영자의 본인 확인과 처리를 시작하는 요청이며 즉시 자동 삭제되는 기능은 아닙니다.
